# DPO GPT-2

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/kkkRina/DPO_GPT2/blob/main/dpo_gpt2.ipynb)

Данный проект посвящён обучению и оценке модели GPT-2, дообученной с помощью метода Direct Preference Optimization (DPO).
Проект включает полный конвейер: подготовка данных, обучение, сохранение результатов и последующая оценка модели.

Главная цель проекта: реализовать пайплайн DPO. Оценка качества первичная (см. раздел «Результаты»).

---

## Результаты

Основные результаты получены в ноутбуке `dpo_gpt2.ipynb`; там же можно посмотреть логи обучения и все выводы. Итоговые файлы сохраняются в папку `results/` (`losses.json`, `eval_results.json`).

| Метрика | Базовый GPT-2 | После DPO |
|---|---|---|
| Точность попарного ранжирования, валидация (300 пар) | 56,0% | 56,7% |
| BERTScore F1 относительно эталонных ответов (50 промптов) | 0,8375 | 0,8380 |

**Как считаются метрики**

- *Точность попарного ранжирования* — доля валидационных пар, для которых суммарная лог-вероятность chosen-ответа выше, чем rejected-ответа (по оценке самой модели).
- *BERTScore F1* — сходство ответов модели на 50 валидационных промптах с эталонными (chosen) ответами.

**О надёжности оценки.** Оценка первичная. Валидационная выборка небольшая (300 пар для точности, 50 промптов для BERTScore), поэтому полученные разницы не позволяют ни подтвердить, ни исключить эффект обучения. Для надёжных выводов нужны большая валидация и доверительные интервалы.

## Метод и данные

- **Модель:** `gpt2` (124M параметров).
- **Данные:** первые 3 000 пар chosen/rejected из датасета Anthropic HH-RLHF; сплит 90/10 (2 700 пар на обучение, 300 на валидацию).
- **Функция потерь (DPO):**

  `L = -log σ( β · [ (log π(y_w|x) − log π_ref(y_w|x)) − (log π(y_l|x) − log π_ref(y_l|x)) ] )`

  где `y_w` — предпочтительный (chosen) ответ, `y_l` — отвергнутый (rejected), `π_ref` — замороженная исходная модель GPT-2.
- **Гиперпараметры:**

| Параметр | Значение |
|---|---|
| β | 0,2 |
| Оптимизатор | AdamW, lr = 1e-5 |
| Максимальная длина последовательности | 384 токена |
| Размер батча | 8 |
| Максимум эпох | 12 |
| Ранняя остановка | по validation loss, patience = 2 |

## Структура проекта

- `data/` — папка для предварительной обработки данных
  - `load_data.py` — скрипт подготовки и токенизации датасета
  - `prepared_pairs.pt` — подготовленные токенизированные данные (создаётся скриптом `load_data.py`)

- `results/` — папка для результатов и сохранённых моделей
  - `eval.py` — скрипт для оценки модели, визуализации и подсчёта метрик
  - `val_raw.json` — файл с валидационными данными (создаётся скриптом `load_data.py`)
  - `eval_results.json` — результаты оценки (создаётся скриптом `eval.py` или ноутбуком)
  - `losses.json` — лог обучения (создаётся скриптом `train_dpo.py`)
  - `dpo_finetuned_gpt2/` — сохранённая обученная модель и токенизатор (создаётся скриптом `train_dpo.py` или ноутбуком)

- `src/` — основная логика тренировки
  - `train_dpo.py` — скрипт тренировки модели с ранней остановкой

- `dpo_gpt2.ipynb` — ноутбук со всеми этапами (данные, обучение, оценка); подходит для облачного запуска

## Использование

Есть два способа запуска: ноутбук (проще, подходит для облака) и отдельные скрипты.

### Вариант 1. Ноутбук

Ноутбук `dpo_gpt2.ipynb` содержит весь пайплайн целиком: подготовку данных, обучение и оценку. Результаты из раздела «Результаты» получены именно через него.

1. Откройте ноутбук в Google Colab (кнопка в начале README) или в Kaggle.
2. Включите GPU. На CPU обучение не рекомендуется: оперативной памяти не хватает.
3. Выполните ячейки по порядку сверху вниз.

Модель и результаты сохраняются в папку `results/`.

### Вариант 2. Скрипты (менее предпочтительный, неактуальная версия)

#### Подготовка данных

Запустите подготовку данных и их токенизацию:

```bash
python data/load_data.py
```
В результате будут созданы файлы:

- `prepared_pairs.pt` — токенизированный датасет для обучения
- `val_raw.json` — исходные данные для валидации

#### Обучение модели

Запустите обучение модели командой:

```bash
python src/train_dpo.py
```

В процессе обучения будут созданы и обновлены файлы и папки:

- `../results/losses.json` — логи значений функции потерь и метрик
- `../results/dpo_finetuned_gpt2/` — сохранённая модель и токенизатор

#### Оценка модели

Запустите скрипт оценки модели:

```bash
python results/eval.py
```

## Ограничения

- Маленькая валидация (300 пар; 50 промптов для BERTScore) и один запуск без доверительных интервалов.
- Обучение на 3 000 парах: для небольшой модели это малый объём данных.
- BERTScore относительно chosen-ответов — лишь косвенная метрика качества ответов.
